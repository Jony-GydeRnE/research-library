CONTEXT TAG QUALITY RULES (read carefully — these are the most common metadata defects):

1. SPECIFICITY: tag each span with what THAT SENTENCE is actually about, not the broad topic of the surrounding section. If the section is about "BCFW recursion" but a sentence defines a complex shift parameter, tag it `bcfw_complex_parameter`, NOT `bcfw_recursion`. Avoid putting the same broad tag on every span in a chunk — distinct sentences should have distinct tags. Tags drive the edge graph, and every distinct concept needs its own anchor.

1b. MULTI-CONCEPT DECOMPOSITION (critical): if a sentence invokes multiple distinct concepts, emit ONE SPAN PER CONCEPT with the SAME sentence range. Do NOT flatten concepts into one span's tag array. The parser accepts overlapping ranges — the same number can appear on many lines.

    [1] Tree amplitudes are rational functions of Lorentz invariant dot products of momenta.
    →
    1 tree_amplitudes definition Ld
    1 rational_functions background Ld
    1 lorentz_invariance definition Ld
    1 dot_product definition Ld
    1 particle_momenta definition Ld

    Rule of thumb: if removing any one concept would change what the reader has to look up, that concept needs its own span. When in doubt, decompose.

2. NORMALIZATION: pick one canonical name per concept. Do not write `uv_scaling` on one span and `enhanced_uv_scaling` and `uv_bcfw_scaling` on others when they all refer to the same concept. Pick the shortest reasonable form (`uv_scaling`) unless the distinction is essential. Same for `hidden_zeros` vs `amplitude_zeros` vs `zero_condition` — choose one.

3. AGGRESSIVE GAP DETECTION (most important rule):
   For every claim, equation, derivation step, or term that is stated without full justification IN THIS PAGE, add an L-tag with TYPE letter:
       Ld = missing definition (uses concept without defining)
       Lv = missing derivation (states result without showing steps)
       Lp = missing proof (asserts without proving)
   Examples:
   - "by the Euler-Lagrange equations" → Lv
   - "the Mandelstam invariants" without defining → Ld
   - "it follows that" without showing why → Lp
   - "applying the Ward identity" → Ld + Lv
   - "as is well known" → Lp
   EVERY chunk should produce at least one L-tag UNLESS it is purely self-contained.
   B (broad external search): substantive unjustified claim that could come from many sources. Prefer L-with-type over B when possible.

ROLE DISAMBIGUATION (read this carefully — these confusions are the most common errors):
• `:=` / `\equiv` / `\mathrel{\mathop:}=` → ALWAYS role=definition. The LHS is the concept being defined; make it the primary contextTag. "BCFW shift := p_i + zq" → definition with tag bcfw_shift. Overrides every other rule when present — notes rely on this operator heavily.
• preview vs proof: if a span describes what WILL BE proved/shown later ("we will prove that…", "we now show that…", "in this section we establish…"), the role is preview, NOT proof. Reserve proof for spans that contain actual derivation steps (algebraic manipulations, case analysis, "because X holds, Y follows", numbered or unnumbered proof steps).
• definition vs background vs section heading: section headings (all-caps lines, bold lines, lines like "UV/BCFW scaling", "AMPLITUDE ZEROS", "I. INTRODUCTION", "Conventions") get role=background, OR if the heading sits on its own line with no defining content, omit the role entirely. Reserve definition for spans that DEFINE a mathematical object or concept ("Let X be...", "We define X to mean...", "An X is a Y such that..."). A heading by itself is not a definition.
• numeric labels: a span whose entire text is just a number ("1.", "2.", "(3)") is NOT a proof step — it's a proof-step LABEL. Skip the role or use remark. Reserve proof for the actual content following the label.

SEARCH-CLASS TAG RULES (important — every claim needs triage):

1. If role = citation: ALWAYS add a search-class tag.
   • External source ([15], [26-31], [Hart77], "Theorem 3 of [AM]") → bare S (no suffix!)
   • Internal reference ("see Section 3.2", "by Theorem 4.1 above") → I{a-z}

2. If the sentence makes a claim the text does NOT fully justify:
   • "it can be shown", "it is obvious", "trivially", "it follows that" → Lp (missing proof)
   • "by the X equations", "from Y theory", "applying Z identity" → Lv (missing derivation)
   • Term used without definition (e.g. "Mandelstam variables", "BCFW shift", "Adler zero") → Ld (missing definition)
   • Substantive claim that could come from many sources, no justification → B{a-z} (broad external search)

3. Only omit the search-class tag for fully self-contained sentences where the claim is proved in the current span or is routine setup/narrative (implicit N).

CRITICAL: S is the ONLY search class with no confidence suffix. Write "S" alone, never "Sa", "Sq", etc. L tags use TYPE letters (Ld/Lv/Lp), NOT confidence — gap matching depends on knowing what KIND of gap. I and B still take a confidence letter (a=~4%, z=~100%).

Declarative tags (optional, precision over recall): p/a/c/e/r/q/s/k/x/d/v followed by chunk.tag (e.g. p14.3, r7.2). ONLY use when the sentence literally performs that relation — when in doubt, omit.

Example:
[1] In [15] the conjecture was proposed that Tr(φ³) amplitudes are uniquely fixed by their zeros.
[2] We prove this conjecture for Tr(φ³) in Section 4.
[3] The proof relies on the hidden zero identity of Theorem 3.2.
[4] It is obvious from the above that the amplitude admits no alternative form.
[5] A similar result holds for loop amplitudes.

Output:
1 hidden_zeros tr_phi3_conjecture citation S
2 hidden_zeros uniqueness_proof preview
3 hidden_zero_identity proof r3.2 Iv
4 amplitude_uniqueness claim Lp
5 loop_amplitudes result Bn
